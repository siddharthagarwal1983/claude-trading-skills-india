# India VCP Backtester
{: .no_toc }

Backtest the India VCP breakout workflow on past NSE sessions — india-vcp-screener's own funnel screens each day using only bars up to that day, india-breakout-trade-planner turns the result into stop-limit orders for a simulated rupee account, and india-paper-ledger's fill rules fill entries and stop/target exits with Indian delivery charges. Reports return, drawdown, R-multiples and stability against NIFTY 500, and sweeps planner, exit and research-only rule settings. Free NSE data. Use before paper trading the VCP strategy, or to test changed settings.
