# India Pre Trade Discipline Gate
{: .no_toc }

Run a pre-trade discipline checklist before placing NSE (India) orders — from an india-breakout-trade-planner plan or a checklist file — blocking planless, oversized, revenge, stale-plan, duplicate and regime- or circuit-breaker-blocked entries, and flagging NSE results due within a few sessions, with every decision journaled. Use right before placing paper or real orders for Indian stocks, after a recent loss, or when the user asks whether a planned Indian trade passes their rules.
